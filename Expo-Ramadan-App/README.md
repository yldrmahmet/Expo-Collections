# İftar Vakti - İmsakiye 2026

Türkiye için sahur ve iftar vakitleri uygulaması.

## Özellikler

- Sahur ve iftar vakitleri
- 81 il desteği
- GPS ile otomatik şehir tespiti
- Offline çalışır (internet gerektirmez)

## Kurulum

```bash
pnpm install
pnpm start
```

## Tech Stack

- Expo SDK 54
- React Native
- NativeWind (Tailwind CSS)
- adhan-js (namaz vakti hesaplama)
